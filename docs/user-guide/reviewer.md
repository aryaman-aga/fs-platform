# Reviewer / EQCR (read-only)

**You can:** view everything on assigned engagements (files, findings, plans, PDFs, audit timeline), run checks
on existing versions, raise and clear review notes. **You cannot** upload, edit, approve plans or release.

1. Open the engagement from **Home**; the **Audit timeline** shows who did what and when (hash-chained, tamper-evident).
2. Compare versions in **Files → Diff**: cells changed, printed figures moved, hidden rows/columns changed.
3. Raise review notes on a finding, a cell, a PDF page or the engagement; assign them to the preparer.
4. Clear notes once the response is satisfactory; cleared notes and their threads go into the engagement archive.
