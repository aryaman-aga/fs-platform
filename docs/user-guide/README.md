**Ground rules for everyone**
- The original upload is never changed; every fix produces a new version you can compare and restore.
- Totals are corrected, never line items; only rounding-sized gaps (≤ 0.20) are balanced, larger gaps are
  reported for investigation (03 §3).
- Narrative notes are corrected as typed text with 2 decimals — never formulas.
- No one approves their own work: plans, AI calls and (for Staff) narrative edits need a second person.
- Do not paste client figures or names into e-mail, chat or tickets; share the engagement link instead.
